# Fakturasjekk.no

Fakturasjekk.no er et norsk forbrukerverktøy for kontroll av faktura mot tilbud, avtale og relevant regelverk.

## Testversjon

Aktuell ekstern testversjon: V0.20.

- Gratis demonstrasjon med syntetiske saker
- Full fakturasjekk + innsigelse er planlagt priset til 29 kr per sak
- Regel- og paragrafkontroll bruker primærkilder
- Testversjonen behandler ikke ekte kundedokumenter

Produksjonsversjonen skal bygges med sikker dokumentopplasting, separat backend, dokumentmotor, versjonert regelmotor og personvern som standard.
