# Fakturasjekk.no – offentlig beta lansert 20.08.2026

## Lanseringsstatus
Fakturasjekk.no er fra 20.08.2026 offentlig tilgjengelig som beta/demo for eksterne testere, samarbeidspartnere og potensielle sponsorer.

## Dette er åpnet
- Offentlig kunde-/testerdemo på GitHub Pages.
- Syntetiske demosaker som viser fakturakontroll, regel- og paragrafkontroll og kontrollert svarutkast.
- Tydelig prisinformasjon: 29 kr for full fakturasjekk + kontrollert innsigelsesutkast når produksjonsflyten åpnes.

## Dette er fortsatt sperret
- Opplasting av ekte kundedokumenter.
- Produksjons-API for kundesaker.
- Ekte betaling og betalingswebhook.
- Behandling av reelle personopplysninger gjennom demosiden.

Dersom en av disse grensene ikke kan verifiseres, skal løsningen forbli fail-closed.

## Betabudskap
Betaen skal omtales som en offentlig produktdemo/testversjon. Den skal ikke fremstilles som en ferdig produksjonstjeneste for ekte fakturasaker før produksjonsportene er eksplisitt åpnet og kontrollert.

## Lanseringsmål
1. Få de første eksterne brukertestene.
2. Måle om brukerne forstår produktet og resultatet uten forklaring.
3. Samle konkret feedback på kundereise, regelvisning og innsigelsesutkast.
4. Starte partner- og sponsordialog.
5. Ferdigstille én sikker ende-til-ende produksjonsflyt frem mot første fremmede betalende kunde.
